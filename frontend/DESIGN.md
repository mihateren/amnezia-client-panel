# Colour roles

The Amnezia logo remains the multicolour brand element. The application uses its palette by meaning, never by card position or user identity.

| Role | Dark theme | Use |
| --- | --- | --- |
| Base | #1D1E22 / #26272D / #2D2E36 | Page, panels, secondary surfaces |
| Action | #FFB66E | Connect, create, save and download |
| Selection | #D1BFEF on #383148 | Current navigation, selected choices and keyboard focus |
| Information | #9AC8D9 on #2E3B43 | Device icons, infrastructure icons, counters and help links |
| Success | #80C8BD on #283E3B | Successful operations and healthy services |
| Error / destructive | #EFD0DE on #47343E | Errors, destructive confirmations and delete hover |

Cards and navigation icons do not alternate colours. Admin Open actions use neutral buttons, as opening details does not change data. Light-theme equivalents preserve the same roles. Text, spacing and layout remain shared between themes.

Colour supplements labels and icons; it is not the sole indication of status or selection. Selected controls retain aria-pressed, navigation retains its active indication, and keyboard focus has a visible outline.
